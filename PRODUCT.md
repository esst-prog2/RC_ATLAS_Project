## Platform

web

## HW9 Implementation

Owner approved plain HTML/CSS with minimal JavaScript and code-first browser variants on 2026-11-12. This is a page-specific choice, not a change to global Impeccable defaults or application architecture.

## Users

Institutional project teams, including programme managers, field coordinators, and monitoring/evaluation teams. The HW9 page also serves classmates, the professor, and visitors unfamiliar with RC Atlas. No customer adoption is claimed.

## Product Purpose

RC Atlas brings project work, monitoring information, indicators, analytics, and reporting into a workspace supporting institutional accountability and decision-making. The owner explicitly confirmed this broader positioning on 2026-11-12; the product must not be reduced to a task-management tool.

## Positioning

Approved headline: **RC Atlas — From institutional data to coordinated action.**

Use the assignment-to-approval workflow as a concrete demonstration of responsibility and review. Operational completion and measured indicator results are distinct. Do not imply a completed task proves institutional impact.

## Operating Context

The application runs locally in a browser. Its featured course workflow follows a task through assignment, execution, submission, validation, and approval. The promotional page will be a separate static GitHub Pages site, subject to publication approval. It will link to the public repository and local setup instructions.

## Capabilities and Constraints

- Project work supports assignments, deadlines, progress updates, and review checkpoints.
- Monitoring includes operational progress and reporting records.
- Configured indicator analysis provides selected methods, periods, results, and explanations; approved definitions and suitable source data are required.
- Selected analytical views include rule-specific data-quality information. Missing configuration and unsupported results are explicitly unavailable.
- Reporting records and report previews exist. Fully governed report/export snapshots remain incomplete.
- Do not advertise predictive analytics, statistical trends, unapproved cross-project aggregates, universal quality scores, or production deployment as ready.
- No backend, security-control, UI-01, or remediation-worktree changes are part of HW9.

## Brand Commitments

Preserve the RC Atlas name, established visual identity, and approved headline. This is a promotional page, not an application redesign. Explain capabilities in plain language. Use no invented endorsements, adoption claims, commercial availability, or fabricated product screenshots.

## Evidence on Hand

## Product Principles

- Keep institutional breadth visible and use a specific workflow to make it understandable.
- Separate reported work progress from measured outcomes.
- Explain data and calculation limitations honestly.
- Publish only the deliberately assembled promotional files after owner approval.

## Accessibility & Inclusion

The owner requires an accessible, responsive, professional, lightweight page for desktop and mobile, understandable without programming knowledge.
